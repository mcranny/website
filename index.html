Current work

At PDF Solutions, I qualify and calibrate six board families using Python and bench instrumentation. This includes developing custom switching hardware, integrating test workflows, and debugging faults that appear during power-up or firmware deployment. I also built a Rust and PostgreSQL system for tracking boards, serialized parts, and their associated software and configurations. My experience page describes the test hardware and production systems.
