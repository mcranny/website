Systems Engineer, PDF Solutions

Overview

I develop automated test systems and embedded hardware for semiconductor manufacturing equipment. My work combines board qualification, instrument control, and firmware debugging, with an emphasis on tracing observed failures to the electrical or software behavior that produces them.

Current work

At PDF Solutions, I qualify and calibrate six board families using Python and bench instrumentation. This includes developing custom switching hardware, integrating test workflows, and investigating faults that appear during power-up or firmware deployment. I also built a Rust and PostgreSQL system for tracking boards, serialized parts, and their associated software and configurations.

Independent projects

My independent work examines programmable digital interfaces, operating-system services, and persistent storage. The protocol emulator ASIC is the largest of these projects: its third revision replaces instruction-dependent output timing with scheduled pin transitions and moves program memory into SRAM. TestOS and the B-tree engine address the interaction between software abstractions and the storage or network behavior beneath them.
