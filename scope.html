How a signal becomes a scope trace.

Browser viewer

Changing timebase to 20 µs/div, trigger level to 0.4 V, and the analog low-pass filter to 0.08 MHz. Initial viewer, adjusted viewer, and capture details.

Through the signal path

A generated waveform passes through modeled converters and an analog path before the scope samples it. The plot shows the sampled waveform and measurements from the full record.

Measuring the full record

The browser draws a reduced set of points so the trace stays responsive. Frequency and peak-to-peak measurements use the complete acquisition record.

Tests check converter errors and filter response, along with trigger placement and measurement results. The scripts and browser viewer use the same acquisition model.
