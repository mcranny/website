Programmable Protocol Emulator ASIC

The protocol emulator implements UART, SPI, I²C, and WS2812 signaling as programs executed by two engines. Its third revision separates instruction execution from pin-transition timing and uses SRAM for program storage. The comparison with V2 explains why that change was necessary and how it affects firmware timing.

TestOS

TestOS is an x86-64 operating system booted through UEFI by Limine. Its storage and network services are exercised in QEMU through shell operations, disk persistence, HTTP transfers, and packet-level TCP checks. The kernel provides preemptive multitasking, a persistent filesystem, and a TCP/IP stack.

B-Tree Storage Engine

This Rust key-value engine stores records in fixed-size pages and uses a redo log to recover interrupted writes. Insertion and deletion preserve tree invariants while a persistent free list makes merged pages reusable. Differential tests compare point lookups and range scans with SQLite after generated operations.
