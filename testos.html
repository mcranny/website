TestOS

TestOS is an x86-64 operating system written in C and booted through UEFI by Limine. It implements persistent storage, networking, and user-space utilities so that file and socket operations can be followed from the shell through kernel services to the device interface. QEMU provides the test environment for disk operations, DHCP, TCP, and HTTP interoperability.

Source repository

System architecture

Limine loads the kernel and supplies the initial execution environment. The kernel provides preemptive multitasking, user-mode execution, and interfaces to the storage and network drivers. User-space programs exercise these services through shell commands, file operations, socket tools, and an HTTP server.

Implemented subsystems and current limits
Boot and processes UEFI handoff through Limine, preemptive multitasking, and user-mode programs
Storage Persistent TFS filesystem with ATA, AHCI, and NVMe data disks
Networking E1000e, ARP, IPv4, ICMP, UDP, TCP, DHCP, and DNS
Input PS/2 keyboard interaction. XHCI controller bring-up
Multiple CPUs Application processors initialize and then park. The boot processor runs the workload

QEMU operation

The recording shows the system reaching its shell, inspecting disks, and downloading a file. It was captured from the same boot image used for the retained tests. The screenshots isolate the terminal regions needed to read the network configuration, HTTP transfer, and filesystem listing.

Testing and results

The retained CI run includes a boot-image build, shell checks against ATA, AHCI, and NVMe data disks, and separate network and HTTP tests. The TCP check opens 25 connections carrying 1,021 bytes each. Packet inspection checks the handshake, data acknowledgments, echoed payload, and connection close, rather than relying only on a successful shell command.

These results were recorded in QEMU. The boot processor runs the workload while additional CPUs remain parked. USB support currently initializes the xHCI controller.
