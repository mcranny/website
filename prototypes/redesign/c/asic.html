Programmable Protocol Emulator ASIC

V3, dual-engine programmable digital interface

Each engine advances a private time cursor and schedules output values and enables. Eight pin cells apply those changes against a shared 48 MHz clock. Programs implement UART, SPI, I²C, and WS2812 signaling.

Execution and timing

The host loads and reads back programs through a 48-clock SPI frame. Each engine schedules pin changes independently; the shared counter supplies deadlines and capture timestamps.

Each engine has a 16-byte transmit queue and a 16-record receive queue. Pin ownership separates the engines’ outputs, while capture records the shared digital interface.

Implementation and results

V3 ran on an Artix-7 Cmod A7-35T with a 48 MHz core clock. Host program loading, readback, and execution were exercised. A Vivado ILA capture recorded a 25 kHz output with 960 samples per half-cycle, equivalent to 20 µs. This is an FPGA digital capture, not an analog signal-quality measurement.

The selected ASIC layout passed 9 physical prechecks and 14 routed-netlist scenarios. Reported slow-corner register setup margin is +2.58 ns; fast-corner hold margin is +0.112 ns. These are physical-design and simulation results, not measurements from fabricated silicon.
