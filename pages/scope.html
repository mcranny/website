Virtual oscilloscope and acquisition path simulator.

A physics-oriented Python package that models signal generation, conversion impairments, analog path behavior, triggering, acquisition buffers, measurements, static visualization, and a browser-based oscilloscope viewer.

Acquisition path

models complete signal chain
1 / waveform

Configurable waveform generation produces deterministic time and signal vectors for repeatable experiments.

2 / DAC

Gain, offset, quantization, ENOB noise, and optional nonlinearity model converter behavior before the analog path.

3 / analog path

Noise, drift, attenuation, low-pass filtering, and fractional sample delay shape the observed signal.

4 / ADC and scope

Sample timing, aperture jitter, quantization, trigger behavior, bandwidth limiting, and acquisition history produce scope records.

Interactive viewer

The viewer uses Python's standard-library HTTP server plus vanilla HTML, JavaScript, and canvas. Controls adjust waveform, converter, analog-path, and scope parameters in the browser.

PYTHONPATH=src python3 -m scope_sim.viewer --host 127.0.0.1 --port 8000

Acquisition endpoint

The viewer serves decimated trace data for display while keeping measurements tied to the full-resolution acquisition record.

GET /api/acquire
{
  "trace": [[time, voltage], ...],
  "measurements": { "frequency": value, "vpp": value }
}

Validation focus

waveform / conversion / triggering / measurement
WaveformsFFT placement, generated waveform shapes, static visualization output, and sample-rate reconstruction behavior.
Converters and analog pathDAC gain/offset and nonlinearities, ADC ENOB/SNR behavior, analog low-pass rolloff, bandwidth limiting, jitter impact, and impairments.
Scope behaviorTrigger behavior, acquisition history bounds, viewer acquisition requests, and measurement accuracy under noisy low-frequency captures.
BoundaryThe zero-phase Butterworth filters make magnitude-response validation simple, but they are not presented as causal analog-front-end phase models.

Minimal usage

README.md
from scope_sim import WaveformGenerator, OscilloscopeEngine, MeasurementEngine

generator = WaveformGenerator(kind="sine", frequency=1_000, amplitude=1.0)
time, signal = generator.generate(n_samples=100_000, sample_rate=1_000_000)

scope = OscilloscopeEngine(
    time_per_div=100e-6,
    divisions=10,
    trigger_level=0.0,
    trigger_edge="rising",
    pre_trigger_fraction=0.5,
)
record = scope.acquire(signal, sample_rate=1_000_000)

measurements = MeasurementEngine(record)
print(measurements.frequency())
print(measurements.vpp())
